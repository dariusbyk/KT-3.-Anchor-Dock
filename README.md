# KT-3. Anchor, Dock
## Описание
Учебный проект со следующими целями:

Цель 1: Создать интерфейс с текстовым полем (TextBox) и кнопкой (Button), которые должны изменять свой размер, сохраняя пропорции при изменении размера окна.

Цель 2: Создать форму с панелью навигации (Panel) слева и рабочей областью (Panel) справа.
